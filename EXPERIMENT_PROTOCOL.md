# Experimental protocol for statistically defensible claims

## Primary factors

- Algorithms: DQN, Double DQN, Dueling DQN, Contextual Bandit (`gamma=0`).
- Independent seeds: 10 by default (42–51).
- CSI quality: 1.0, 0.8, 0.5.
- Feedback delay: 0, 1, 3 environment steps.
- Codebook: DFT; Zadoff–Chu is prevalidated and automatically retained/dropped according to oracle-gain coverage.
- Channel: 3GPP TR 38.901-inspired UMa surrogate by default; DeepMIMO adapter is available.

## Statistical unit

The independent unit for uncertainty is the **training seed**. Episode-level samples within one seed are not treated as independent replicates for confidence intervals.

For each condition, the package reports a two-sided 95% Student-t CI over the seed-level evaluation metric. Algorithm differences are also paired by seed and condition before computing the CI.

This does not replace a full hierarchical or repeated-measures analysis when the experimental design becomes more complex. It is a transparent baseline suitable for the current benchmark.

## Zadoff–Chu decision rule

The codebook validation stage estimates the maximum normalized beamforming gain over fresh channel draws for DFT and ZC. The package computes:

`mean ZC oracle gain / mean DFT oracle gain`

ZC is retained only if the ratio is at least `zc_min_relative_gain` (default 0.95). Otherwise the main benchmark uses DFT and the validation result records why ZC was dropped. This prevents a mathematically defined ZC construction from being presented as a useful beam codebook without empirical coverage evidence.

## Imperfect CSI

For CSI quality `q`, the receiver-side estimate is:

`h_hat = normalize(sqrt(q) h + sqrt(1-q) e)`

where `e` is an independent normalized complex fading vector. This is a controlled sensitivity model, not a full pilot/estimation-chain model.

## Feedback delay

At delay `d`, the beam-selection agent observes a channel estimate based on `h[t-d]` while reward is computed using the current channel `h[t]`. Channel evolution is generated by normalized additive innovations controlled by `mobility`.

## Channel-model qualification

The included 3GPP option is a **surrogate inspired by TR 38.901 UMa clustered stochastic modeling**. It is intentionally not claimed to reproduce every standard parameter, path-loss model, LSP correlation, delay profile, polarization effect, or spatial-consistency procedure. A publication claiming standards-compliant 38.901 simulation should substitute a validated implementation and record its version/configuration.

For DeepMIMO, the benchmark consumes exported channel coefficients so that the same learning/evaluation code can be run on site-specific or measured-derived channels.

## Claim language

Preferred: “Across 10 independent seeds, the estimated difference was X with a 95% CI of [L,U].”

Avoid: “Algorithm A is statistically better” unless the reported CI and the pre-specified comparison actually support that statement.

If a CI crosses zero, report the estimate and uncertainty without declaring a difference.
